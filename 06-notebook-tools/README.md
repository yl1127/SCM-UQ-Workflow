# Notebook Tools

These scripts generate interactive notebooks under `notebooks/`.

| Tool | Notebook |
| --- | --- |
| `scripts/create_baseline_observation_interactive_notebook.py` | `notebooks/ARM97_baseline_vs_observation_interactive.ipynb` |
| `scripts/create_stitched_observation_interactive_notebook.py` | `notebooks/ARM97_stitched_vs_observation_interactive.ipynb` |
| `scripts/create_iop_interactive_notebook.py` | `notebooks/IOP_observation_interactive_plots.ipynb` |
| `scripts/create_qmc_interactive_scatter_notebook.py` | `notebooks/QMC_interactive_scatter_expanded_variables.ipynb` |

The generated notebooks infer the repository root from the current directory.
Opening them from the repository root or from `notebooks/` is supported.
